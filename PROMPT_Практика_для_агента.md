# Промпт для следующего агента: вкладка «Практика» в EPDeutsch Wörter

Привет! Ты продолжаешь разработку вкладки **«Практика»** на сайте EPDeutsch Wörter: подготовка к Ergänzungsprüfung Deutsch (EPD) в Австрии. Владелец пишет по-русски. Отвечай ему коротко, по-русски, простыми словами и показывай скриншоты.

Сначала прочитай `AGENTS.md` в корне репозитория (правила проекта) и этот файл целиком.

---

## 1. Где что лежит

- Общая папка проектов: `~/EPDeutsch/`. Сайт: `~/EPDeutsch/EPDeutschWorter/` (git, ветка `main`). `~/UniSicherDeutsch` — ярлык на него.
- Будущие проекты (EPDeutsch Lesen и т. д.) создаются рядом: `~/EPDeutsch/EPDeutschLesen/` и т. п.
- Работа над «Практикой» идёт в ветке **`agent/practice-tab`**, рабочая копия (worktree):
  `~/EPDeutsch/EPDeutschWorter/.claude/worktrees/practice-tab`. **В main ещё не влита.**
- В этой рабочей копии `db` — **ярлык (symlink) на настоящую базу** `~/EPDeutsch/EPDeutschWorter/db/`. Он показывается в `git status` как `?? db`. **Никогда не коммить его.** Тестовая база лежит в `db.test/`.
- Резервная копия настоящей базы (сделана перед первым запуском с ИИ): `~/EPDeutsch/EPDeutschWorter/db/backup-20261001/unisicher.db`.

## 2. Правила работы (обязательно)

- Работай в своём worktree и своей ветке `agent/<задача>` (или продолжай в `agent/practice-tab`, если владелец не против). Не делай `checkout`/`stash`/`reset --hard` в основной папке: там бывают другие агенты.
- `index.html` — единственный источник правды для фронта. **Не запускай `tools/build.py`**, он затрёт `index.html`.
- Бэкенд `server.py` — **только стандартная библиотека Python**, без pip. Внешние API вызываются через `urllib` (так же, как DeepL).
- `db/` (база, ключи, логи) в git не коммитить никогда.
- После правки `data/` запускай `python3 tools/check.py`.
- Продумывай пограничные случаи: прогоняй функцию по всем карточкам, учитывай формы слов.
- Перед проверкой в браузере проверь синтаксис главного `<script>`: node в системе нет, используй JavaScriptCore через `osascript -l JavaScript` (`new Function(code)`).
- Запуск сайта: `python3 server.py 8765` → http://localhost:8765. Для тестов бери отдельный порт и отдельную базу: `UNISICHER_DB=/путь/test.db python3 server.py 8797`.
- Сливать в main — **только когда владелец попросит**: `git rebase main` в ветке → проверка → из основной папки `git merge --ff-only`.

## 3. Ключи API — важно

- Ключи лежат в файлах **`db/anthropic.key`** и **`db/openai.key`** (или в переменных `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`). Владелец кладёт их сам командой `pbpaste > ~/EPDeutsch/EPDeutschWorter/db/anthropic.key`.
- 2026-10-01 владелец прислал ключи прямо в чат. Его попросили удалить их и выпустить новые. **Ключи из истории чата не используй никогда.** Ключ вида `sk-ant-usr-…` — не ключ API, настоящий начинается с `sk-ant-api03-`.
- Если владелец снова пришлёт ключ в чат: не сохраняй его, попроси перевыпустить и положить через `pbpaste`.
- Без ключа Claude сайт работает в **тестовом режиме**: предложения проверяет только LanguageTool.
- Проверить, что ключ на месте, не показывая его: `test -s db/anthropic.key && head -c 13 db/anthropic.key`.

## 4. Что уже сделано (ветка `agent/practice-tab`)

**Вкладка «Практика»** стоит в меню после «Карточек» (и в нижней панели на телефоне). В ней два режима:

1. **«Пиши предложения» — работает по-настоящему.**
   - Слова берутся из выученных в карточках. После практики слово возвращается через 2, 5, 12, 30 и 60 дней, примерно каждое третье — повторение. История хранится в `S.pw[id] = [день, сколько раз]` и синхронизируется с аккаунтом.
   - `POST /api/practice/check` → LanguageTool (`de-AT`, публичный API, лимит около 20 запросов в минуту) → Claude Haiku 4.5 (`claude-haiku-4-5`) со строгим JSON (`output_config.format`, схема `CHECK_SCHEMA`) → ответ: verdict, исправленный вариант, ошибки с объяснением по-русски, правильно ли употреблено слово, оценка 1–5, подсказка для C1.
   - Кэш одинаковых проверок: таблица `ai_cache`, хранится 30 дней.
   - Фронт: `prWrite`, `prResult`, `prMark` в `index.html`. Отправка по ⌘/Ctrl+Enter.
   - **С настоящим ключом Claude ещё не тестировалось** (проверен только путь запроса с неверным ключом, 401 обрабатывается). Первым делом прогони 10–15 разных предложений и настрой `CHECK_SYSTEM`.
2. **«Разговор с ИИ» — пока заглушка интерфейса** (`prTalk`): выбор формата устной части EPD (свободный разговор, презентация, дискуссия, вопросы экзаменатора), тема из глав учебника, чат, кнопка микрофона (пока только всплывающее сообщение), блок «Разбор после разговора».

**Предохранитель** (`ai_guard` в `server.py`). Для пользователей лимитов нет, ИИ отключается только при явном сбое:
- больше `AI_USER_MIN = 30` запросов в минуту на аккаунт → пауза на минуту;
- больше `AI_USER_DAY = 450` в день на аккаунт или больше `AI_SITE_DAY_USD = 3.0` в день на весь сайт → «ИИ отдыхает до завтра»;
- каждое срабатывание пишется в `ai_log` с `kind='block'`. Владельцу уходит письмо, одно на причину в день. В админке оно видно как «Подозрительная активность».
- Все вызовы ИИ пишутся в `ai_log` (без текстов): токены, стоимость в микродолларах, время, ошибка. Функция `ai_log(c, uid, kind, model, inp, outp, ms, err)`. Цены в `AI_PRICE`.

**Админка → карточка «Расходы ИИ»** (`admAI` во фронте, `ai_stats` на сервере, приходит в `/api/admin/overview` как `ai`).

**Важно:** `ai_guard` и ошибки ИИ делают `c.commit()` перед `raise ApiError`, потому что `with db()` откатывает транзакцию при исключении. Делай так же в новых местах.

## 5. Решения владельца (не переспрашивай)

- Пользователей пока двое (владелец и коллега). Каждый хочет примерно **5 разговоров и 20–30 предложений в день**. Лимитов не нужно, только предохранитель от сбоя. Бюджет примерно $25–30 в месяц на двоих.
- Модели: **Haiku 4.5** для проверки предложений и реплик экзаменатора, **Sonnet 5.5** (`claude-sonnet-5-5`) только для итогового разбора разговора. Цены: Haiku $1 / $5, Sonnet 5.5 $2 / $10 за 1 млн токенов (вход / выход).
- LanguageTool — да. Пока публичный API, позже можно поставить свой сервер (`LANGUAGETOOL_URL`).
- Город сдачи пока неизвестен (Вена или Грац) → формат экзаменатора строим **по официальной модели VWU**.
- Исправления в разговоре: **переключатель «Режим экзамена / Режим урока»**. В режиме экзамена экзаменатор только переспрашивает и помогает исправиться самому, разбор в конце. В режиме урока сразу коротко поправляет по-русски.
- Микрофон: **нажал — говоришь — нажал ещё раз**, с видимым таймером.
- Озвучка ответов: бесплатный синтез речи браузера (`speak()` уже есть; лучшие голоса в Edge и Mac Premium).
- Распознавание речи: OpenAI (Whisper или `gpt-4o-mini-transcribe`, ориентировочно $0,003–0,006 за минуту — **проверь актуальную цену и модель перед реализацией**).
- После «Практики»: **оптимизация сайта**, затем новый проект **EPDeutsch Lesen**.
- Главное требование владельца: всё максимально **просто и интуитивно**, пользователь не должен думать, как этим пользоваться. И максимально **похоже на настоящий EPD**.

## 6. Официальный формат EPD (источник для экзаменатора)

Источник: https://www.vwu-info.at → PDF «EPD_MODELL MIT HV_GÜLTIG AB JUNI 2026_FINAL.pdf», 42 страницы. В URL буква «Ü» кодируется как `U%CC%88`. Текст из PDF можно достать через PDFKit: `swift` со скриптом, `PDFDocument(url:).page(at:).string`. Коммерческим сайтам с другими таймингами не верь.

**Устная часть** (допуск только после сданной письменной):
- **Монолог:** дают 2 задания из разных тем (график, статистика, короткий текст, карикатура, цитата), выбрать одно. Подготовка **не меньше 15 минут**, одноязычный словарь, заметки. **Презентация около 5 минут** по 5 наводящим вопросам. Схема вопросов: перескажи → как у тебя на родине → плюсы и минусы → твоё мнение → предложи меры. Говорить свободно, не читать.
- **Диалог:** материал (картинка, простой график, цитата, тезис) дают **после** презентации. **Около 5 минут** разговора без подготовки, 4–6 вопросов.
- Комиссия из 3 человек, оценка 1–5.
- **Что оценивают:** не знания, а язык. Понимает вопросы и реагирует; умеет сказать «не понял», «не согласен», «мало знаю о теме»; исправляет ошибки с помощью экзаменатора; понятно без усилий. Заученный текст не засчитывается. Говорить без ошибок не обязательно.

**10 официальных тем:** Arbeitswelt und Wirtschaft · Beziehungen und Geschlechtergerechtigkeit · Gesellschaft und soziales Engagement · Konsumgesellschaft · Körperliche und mentale Gesundheit · Lernen, Bildung, Studium, Wissenschaft · Medien (вкл. KI) · Tourismus und Reisen · Wohnen · Umwelt. Каждую спрашивают под одним из ракурсов: Globalisierung, Digitalisierung, Nachhaltigkeit, Zukunftstrends.

**Письменная часть** (180 мин, для будущих модулей): Lesen 50 мин / 20 баллов, Hören 35 / 15, Strukturen und Wortschatz 35 / 15, Textproduktion 60 / 25 (выбрать 1 из 2, материал — текст или график). По каждой части нужен минимум и всего не меньше 45 из 75.

Грац (VGUH): уровень C1, два экзаменатора, формат в регламенте не расписан.

## 7. Задачи по порядку

1. **Подключить Claude по-настоящему** (когда владелец положит ключ). Прогнать 10–15 предложений: правильные, с ошибками в падежах и артиклях, с неправильным употреблением слова, не по-немецки, с попыткой подсунуть команду. Настроить `CHECK_SYSTEM`. Убедиться, что расходы пишутся в `ai_log` и видны в админке.
2. **Разговор с ИИ (уровень 2):**
   - запись в браузере (MediaRecorder): нажал, говоришь, нажал; таймер; максимум 2 минуты на одну запись;
   - `POST /api/practice/stt` → OpenAI, ключ `db/openai.key`; запись в `ai_log` (kind `stt`, цена за минуту);
   - показать распознанный текст пользователю;
   - `POST /api/practice/talk` → Haiku в роли экзаменатора: формат, тема, режим экзамена или урока, история; ответ озвучивает `speak()`;
   - итоговый разбор через Sonnet 5.5: 3 главные ошибки, слова из темы (в том числе из выученных карточек), оценка 1–5 по критериям EPD;
   - всё через `ai_guard`; ограничить длину разговора (около 20 реплик).
3. **«Пробный экзамен»** — полная копия устной части: выбор из 2 заданий → таймер подготовки 15 минут с полем для заметок → презентация 5 минут → новый материал → разговор 5 минут → оценка и разбор. Плюс короткие **тренировки** отдельных частей. Материалы: графики рисует сайт сам (учебные данные, подписать), короткие тексты сгенерировать заранее и проверить, цитаты брать только без авторских прав. Карикатуры и фото из интернета не брать.
4. **Политика конфиденциальности:** дописать, что тексты и голос передаются Anthropic, OpenAI и LanguageTool (LanguageTooler GmbH). Не забыть про остальные задачи перед запуском: контактная почта, Impressum, проверка юристом.
5. **Влить ветку в main** — когда владелец скажет.
6. **Оптимизация сайта:** скорость загрузки, телефон, расходы на ИИ.
7. **EPDeutsch Lesen** — отдельный проект в `~/EPDeutsch/EPDeutschLesen/`, по архитектуре EPDeutsch Wörter.

## 8. Как проверять

- Серверные функции удобно тестировать прямо из Python: `UNISICHER_DB=/tmp/x.db python3 -c "import server as S; S.init_db(); …"`. Так проверялся предохранитель: минутный, дневной лимит и бюджет, письмо владельцу один раз, удаление аккаунта.
- Внешние API зови по-настоящему только с согласия владельца: каждый вызов стоит денег.
- Тестовые аккаунты создавай только на локальной тестовой базе, а не на настоящей.
- В конце каждой задачи: скриншот, короткий итог по-русски, имя ветки и путь к worktree.
