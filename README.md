# Deutsch — личная учебная платформа

Подготовка к **Ergänzungsprüfung Deutsch (EPD)** и бонус-тестам VWU плюс «свободный немецкий» для жизни.
Вход по приглашению, прогресс сохраняется в аккаунте, друзья и рейтинг — в Wörter. Английский — отдельная категория, позже.

> 🤖 **Ты агент?** Сначала прочитай [AGENTS.md](AGENTS.md) и `~/EPDeutsch/ПРОГРЕСС_и_промпт.md`.

## Быстрый старт

Нужен только Python 3.9+ (без зависимостей).

```bash
python3 server.py 8765
```

Открыть http://localhost:8765 → вход → Deutsch. База SQLite создастся сама в `db/unisicher.db`.
Ключи API (Claude, OpenAI, DeepL) владелец вставляет на странице `/de#/settings` — они ложатся в `db/*.key`.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Весь фронтенд (SPA, ~830 КБ). **Единственный источник правды** — правится напрямую. |
| `server.py` | Бэкенд: только стандартная библиотека Python + SQLite. Аккаунты, синхронизация, друзья, наборы, админка, SEO, gzip/ETag. |
| `data/*.json` | Словарь по разделам учебника (`1.1` … `5.3`), `exams.json`, `hoeren.json`, `A2.json`. |
| `src/*.txt` | Компактные исходники разделов → конвертируются в `data/` через `tools/txt2json.py`. |
| `tools/check.py` | Проверка `data/*.json` (поля, дубликаты, разметка). |
| `tools/build.py`, `tools/template.html` | ⚠️ **Устарели.** `build.py` перезапишет `index.html` старой версией — не запускать. |
| `static/` | Иконки, og-картинка. |
| `db/` | Живая база, ключи, логи — **в git не попадает** (см. `.gitignore`). |
| `PROMPT_EPMathe_для_коллеги.md` | Полное ТЗ на EPMathe (актуальная версия). |
| `PROMPT_EPM_для_друга.md` | Более ранняя, короткая версия того же ТЗ (без раздела про общий аккаунт). |
| `epmathe-demo.html` | Эталон дизайна EPMathe — открыть двойным кликом. |

## Переменные окружения (хостинг)

| Переменная | Зачем |
|---|---|
| `PORT` | Порт (или первый аргумент `server.py`). |
| `SITE_URL` | Адрес сайта для canonical / sitemap / og:image. |
| `PROXY=1` | За HTTPS-прокси: IP из `X-Forwarded-For`, cookie с `Secure`. |
| `UNISICHER_DB` | Путь к базе вместо `db/unisicher.db`. |
| `DEEPL_API_KEY` | Переводчик в редакторе карточек (или файл `db/deepl.key`). |
| `OWNER_EMAILS` | Почты админов (или файл `db/owner.txt`). |
| `GOOGLE_SITE_VERIFICATION`, `YANDEX_VERIFICATION`, `BING_VERIFICATION` | Коды поисковиков. |
