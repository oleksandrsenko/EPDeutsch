# Инструкция для AI-агента

Привет! Ты открыл репозиторий **EPDeutsch**. Здесь две вещи:

1. **Рабочий продукт EPDeutsch** — подготовка к Ergänzungsprüfung Deutsch (весь код в корне).
2. **ТЗ на новый продукт EPMathe** — подготовка к Ergänzungsprüfung Mathematik.

## Твоя задача (если тебе не сказали иначе): построить EPMathe

1. Прочитай целиком **[`PROMPT_EPMathe_для_коллеги.md`](PROMPT_EPMathe_для_коллеги.md)** — это твой промпт/ТЗ.
   Всё, что ниже линии `---` в этом файле, — инструкции тебе от владельца проекта.
2. Открой и прочитай **[`epmathe-demo.html`](epmathe-demo.html)** — эталон дизайна (токены, компоненты, логотип, график, конфетти).
3. EPDeutsch в этом репозитории — **образец архитектуры и UX**, на который ссылается ТЗ:
   - `index.html` — как устроены экраны, меню, темы, карточки, серия/XP, вход/регистрация;
   - `server.py` — как устроены пароли (PBKDF2-SHA256), сессии, cookie, API, gzip/ETag;
   - `data/*.json` + `tools/check.py` — формат данных и проверка.
   Бери оттуда решения, но **не переписывай и не ломай EPDeutsch**.
4. EPMathe делай в **отдельном репозитории/папке** (например `EPMathe/`), а не поверх этого кода.
5. Раздел 6 ТЗ (единый аккаунт, `accounts.db`, схема, cookie) — **контракт**, отступать нельзя.
6. Порядок работы — раздел 7 ТЗ: сначала план файлов и схема данных → каркас по демо → показать скриншот и ждать «ок».

Отвечай владельцу по-русски, коротко, со скриншотами.

## Если работаешь над самим EPDeutsch

- `index.html` — единственный источник правды. **Не запускай `tools/build.py`** — он затрёт `index.html` устаревшим шаблоном.
- В `index.html` есть блоки `<!--B:ru-->…<!--/B:ru-->`, `<!--B:en-->`, `<!--B:epd-->` — сервер выбирает блок по адресу (`/`, `/en`, `/epd`). FAQ в JSON-LD и видимый FAQ правь вместе.
- Бэкенд — только стандартная библиотека Python, без pip-зависимостей.
- После правки `data/` — `python3 tools/check.py`.
- Продумывай пограничные случаи: прогоняй фичи по всем карточкам, учитывай синонимы и формы слов в данных.
- Запуск: `python3 server.py 8765` → http://localhost:8765.
- `db/` (база, ключи, логи) в git не коммитить никогда.
