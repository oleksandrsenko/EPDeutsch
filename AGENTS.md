# Инструкция для AI-агента

Это **личная учебная платформа** владельца (не коммерческий проект). Отвечай по-русски, коротко, со скриншотами.
Перед работой прочитай `../../ПРОГРЕСС_и_промпт.md` (в папке `~/EPDeutsch/`): там что сделано, что осталось и промпт для тебя.

## Что где

| Адрес | Файл | Что это |
|---|---|---|
| `/` | `start.html` | Вход / регистрация по приглашению → выбор языка (Deutsch, English — позже) |
| `/de` | `de.html` | Немецкий: обзор с планом дня, Grammatik, Lesen, Hören, Sprechen, «Свободный немецкий», План, Настройки (SPA на hash-маршрутах `#/lesen/<id>` …) |
| `/woerter` | `index.html` | Wörter — карточки слов (не переделывать структуру, владельцу она нравится) |
| `/schreiben` | `../EPSchreiben/schreiben.html` | Schreiben — отдельный репозиторий рядом |
| `/api/de/*` | `lernen_api.py` | прогресс модулей (таблица `kv`), перевод слова (DeepL + Claude Haiku), озвучка (OpenAI TTS, кэш `db/audio/`), распознавание речи, разбор Sprechen (Claude Sonnet), ключи и приглашения |
| — | `server.py` | сервер: аккаунты, Wörter, друзья, Schreiben, раздача файлов. Только стандартная библиотека Python |
| — | `static/ep.js` | общее: аватары, талисман, **верхняя панель модулей `EP.modbar()`** и **поиск `EP.search()` (⌘K)** |

Контент — JSON, правится руками: `data/de/{grammatik,lesen,hoeren,sprechen}.json` (подготовка к EPD) и
`data/frei/{grammatik,lesen,hoeren,sprechen,wendungen,videos}.json` («Свободный немецкий», с EPD не пересекается).
После правки — `python3 tools/check_lernen.py`. Аудио Hören заранее: `python3 tools/gen_audio.py` (нужен `db/openai.key`).

## Правила

- Стек не менять: Python stdlib + ванильный JS, без сборщиков и pip-зависимостей. Лёгкость важна (MacBook Air M2).
- `index.html` — единственный источник правды для Wörter. **Не запускай `tools/build.py`** — затрёт `index.html`.
- `db/` (база, ключи, аудио-кэш) в git не коммитить никогда.
- Регистрация закрыта: первый пользователь — владелец, остальные только по коду приглашения (Настройки → Приглашения).
- Уровень заданий — от B2 к C1, по нарастающей. Темы — 10 тем EPD (см. `TOPICS` в `de.html`).
- Продумывай пограничные случаи и проверяй в браузере.
- Запуск: `python3 server.py 8765` → http://localhost:8765. Для проверки без живой базы: `UNISICHER_DB=/tmp/test.db python3 server.py 8792`.
- Параллельные агенты: каждый в своём git worktree и ветке `agent/<задача>` (см. глобальный CLAUDE.md владельца).
