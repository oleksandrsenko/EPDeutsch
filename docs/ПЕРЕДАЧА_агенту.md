# Передача работы другому ИИ-агенту (GPT ASTRA 6.0)

Ты продолжаешь личную учебную платформу «EPDeutsch» (подготовка к EPD, Вена). Отвечай по-русски, коротко. Стек: PHP + MySQL на InfinityFree, фронт — ванильный JS, без сборщиков и npm.

## Где код
- Репозиторий: `~/EPDeutsch/EPDeutschWorter`, твой worktree: `~/EPDeutsch/EPDeutschWorter/.claude/worktrees/epd-format`, ветка `agent/epd-format`. В `main` не коммить и не сливай. Чужие worktree не трогай. Коммиты маленькие, `git add` только своих путей.
- Сначала прочитай `~/EPDeutsch/ПРОГРЕСС_и_промпт.md`, `AGENTS.md`, `docs/ПЕРЕДАЧА_агенту.md`.
- Фронт: `public/de.html` (главная страница модулей), `public/de-core.js` (повтор запросов, шаги ИИ, таймер, перетаскивание), `public/de-tasks.js` (типы заданий, баллы, локальные Satz einfügen и Lückentext, генерация Lesen/Hören/Grammatik), `public/schreiben.html`.
- Сервер: `app/Lernen.php` (маршруты `/api/de/*`), `app/Gen.php` (короткие шаги ИИ), `app/AiGen.php`, `app/Ai.php`, `app/Schreiben.php`, промпты в `app/prompts/`.
- Данные: `public/data/de/*.json`. Hören собирается из `tools/hoeren_src/<id>.txt` командой `python3 tools/build_hoeren.py` (формат описан в начале скрипта; он сам проверяет длину ≥1000 слов, 7 вопросов, 8 пропусков, что ответы звучат в записи).
- Заливка на сайт: `tools/make_package.sh <имя>` собирает пакет в `~/EPDeutsch/_infinityfree_upload/update-<имя>/`; заливает пользователь сам: `bash ~/EPDeutsch/_infinityfree_upload/deploy.sh` (FTP-пароль ты не видишь). PHP кладётся как `htdocs/app/...`.
- Локальный стенд: MariaDB в docker (`epd-php-mariadb`, порт 33306, база `epd_dev`), `php -S 127.0.0.1:8821 -t public scripts/dev-router.php` с конфигом из `EPD_CONFIG`, имитация Anthropic/OpenAI на порту 8830 (скрипт `mock.py` лежал в scratchpad прошлой сессии, при необходимости напиши заново). Живых ключей нет: ответы ИИ реально не проверены.
